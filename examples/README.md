# Examples

Real-world cards from the EAM-DISLOCS-Ni-Cu project (D90 edge dislocation in
Ni with SGCMC Cu segregation, 568k atoms). The dumps are not shipped; point
`input.file` / `grid.inputs` at your own copies.

- `d90-dxa.yaml` — view along the dislocation line (front view).
- `d90-dxa-top.yaml` — glide-plane view: slab around the (111) glide plane,
  SF ribbon between the two Shockley partials, Cu decoration, DXA lines.
- `d90-evolution-grid.yaml` — `ovzm grid`: the glide-plane view at two MC
  steps, identical camera/scale across panels.
- `ovzm-project.yaml` — project-scoped attribution (creator, funding,
  per-person affiliations); the cards here carry no `meta:` because this
  file supplies it.
