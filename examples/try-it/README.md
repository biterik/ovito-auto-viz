# Try it in five minutes

A tiny, fully self-contained example — nothing to download, no simulation
code needed. A ~90 Å fcc Ni box with four edge dislocations (a quadrupole:
two opposite dipoles, so the box is a closed system with **net b = 0**) is
generated by a numpy-only script; `ovzm` + DXA then work out everything the
figure says about the dislocations from the positions alone.

```bash
cd examples/try-it
python make_edge_dipoles.py        # ~14k atoms, full PBC, a few seconds
ovzm info edge-dipoles.dump           # what the file does (and does not) carry
ovzm render edge-dipoles.yaml --ask   # asks once who you are: attribution is mandatory
ovzm prov edge-dipoles__edge-dipoles.png   # the receipt, straight from the PNG
```

(If you prefer not to be asked, put `creator: Your Name` into
`~/.config/ovzm/identity.yaml` once — see the Attribution section of the
main README. The `ovzm-project.yaml` in this directory deliberately sets
only the project name, not a creator: the figure's creator is you.)

The rendered figure labels itself. Expected label block, computed — not
typed by anyone:

```
DXA: 4 segment(s), L = 69 Å
  net b = 0 (closed box)
  b = 1/2[-110] (perfect), ξ = [-1-12], 90° edge, L = 17 Å (PBC-infinite)
  b = 1/2[-110] (perfect), ξ = [-1-12], 90° edge, L = 17 Å (PBC-infinite)
  b = 1/2[1-10] (perfect), ξ = [-1-12], 90° edge, L = 17 Å (PBC-infinite)
  b = 1/2[1-10] (perfect), ξ = [-1-12], 90° edge, L = 17 Å (PBC-infinite)
```

Four perfect a/2⟨110⟩ edge dislocations along [-1-12], pairwise opposite —
exactly what `make_edge_dipoles.py` inserted, recovered from raw positions.
The provenance embedded in the PNG additionally records the input file's
SHA-256, the fully resolved card and scene, and DXA's measured lattice
constant (≈ 3.52 Å for Ni).

`tests/test_example_physics.py` asserts all of this in CI, so the example
is guaranteed to keep working.

Things to try next: change `view.direction` to a Miller triplet like
`[1, 1, 1]`; switch `output.preset` to `paper`; set `atoms.show: all` to see
the whole crystal; or open the pipeline interactively with
`ovzm session edge-dipoles.yaml`.
